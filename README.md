# Liora Patisserie — Website Concept Demo

A soft, classic bakery website concept created by Thunder Fox Web Solutions.

## Design
- Warm cream, blush, and cocoa palette
- Playfair Display + DM Sans typography
- Responsive layout for mobile and desktop
- Product collection, story, gallery, contact details, and enquiry CTAs
- WhatsApp enquiry flow prompts for a number so this concept does not accidentally contact a real person

## Before using for a real bakery
This is a concept demo, not a real business website. Replace the sample brand name, products, prices, images, address, opening hours, and all contact information with details approved by the bakery owner. Confirm image usage rights and replace any images as needed. Configure the owner's WhatsApp number and test the full customer journey before launch.

## Deploy
Static HTML/CSS/JS. Connect this repository to Vercel; no build command is required and the output is the repository root.
